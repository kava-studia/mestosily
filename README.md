# Место Силы

Демо-сайт глэмпинга в деревне Марино, Сергиево-Посадский городской округ.

## Что уже работает

- адаптивный лендинг
- интерактивный календарь выбора дат
- демонстрационные занятые даты
- выбор количества гостей
- выбор домика
- выбор бани, чана, сапа или лодки
- форма заявки
- серверный обработчик `/api/booking`
- автоматическая отправка в Telegram после добавления переменных окружения
- карта Яндекс с карточкой объекта

## Telegram

В Vercel нужно добавить две переменные окружения:

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

Если переменные не заданы, форма работает в демо-режиме и возвращает успешный ответ без отправки сообщения в Telegram.

## Календарь

Сейчас занятые даты генерируются как демонстрационные. Следующий этап - заменить их на данные из простой базы или админ-панели, чтобы хозяева сами отмечали брони.

## Фотографии и логотип

Финальные фотографии и исходный логотип следует хранить в репозитории без перекодирования и подключать как обычные статические файлы. Так Vercel отдаёт оригиналы напрямую, без обязательного изменения качества исходников.
